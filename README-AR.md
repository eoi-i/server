# GLOBALHOLMES LTD — موقع الوكالة

موقع تعريفي عربي متجاوب متعدد الصفحات، مبني باستخدام HTML وCSS وJavaScript، ويعمل داخل حاوية Nginx على Fly.io.

## محتويات الموقع
- `index.html` الصفحة الرئيسية
- `about.html` من نحن والمديرة
- `services.html` الخدمات
- `creators.html` صفحة المبدعين وطلب التعاون
- `faq.html` الأسئلة الشائعة
- `contact.html` معلومات التواصل
- `privacy.html` سياسة الخصوصية
- `assets/director-maryam.png` الصورة المرفقة للمديرة
- `assets/website-preview.png` صورة معاينة التصميم
- `Dockerfile` و`nginx.conf` و`fly.toml` للنشر على Fly.io

## النشر على Fly.io

1. فك ضغط الملف على جهازك أو داخل Termux.
2. ثبّت Fly CLI وسجّل الدخول:
   ```bash
   fly auth login
   ```
3. افتح مجلد المشروع:
   ```bash
   cd globalholmes_site
   ```
4. غيّر قيمة `app` داخل `fly.toml` إلى اسم تطبيق Fly.io فريد وغير مستخدم.
5. أنشئ التطبيق إذا لم يكن قد أُنشئ:
   ```bash
   fly apps create اسم-تطبيقك
   ```
   ثم تأكد أن قيمة `app` في `fly.toml` تطابق الاسم.
6. انشر:
   ```bash
   fly deploy
   ```
7. افتح الموقع:
   ```bash
   fly open
   ```

## ربط النطاق الخاص
بعد شراء/امتلاك النطاق، أضفه إلى تطبيق Fly.io من لوحة Fly أو باستخدام:
```bash
fly certs add example.com
```
ثم أضف سجلات DNS التي تعرضها Fly.io حرفياً لدى مزود النطاق.

## ملاحظات مهمة قبل الإطلاق
- الموقع واجهة تعريفية ثابتة ولا يحتوي حالياً على لوحة إدارة أو تسجيل دخول أو قاعدة بيانات.
- سياسة الخصوصية مسودة عامة ويجب مراجعتها قانونياً واعتمادها وفق إجراءات الشركة الفعلية.
- لا تستخدم شعارات TikTok بطريقة توحي بأن الوكالة هي TikTok نفسها أو أنها تابعة لها ما لم يكن لديك تفويض رسمي. النص الحالي يصف الوكالة بأنها مستقلة.
- صورة المعاينة في `assets/website-preview.png` تصور الشكل المقترح، أما صفحات الموقع الفعلية فتستخدم التصميم والملفات البرمجية المرفقة.
- استبدل أي بيانات وصفية أو وصف خدمات لا يطابق نشاط الشركة الفعلي قبل النشر.
